# Code of conduct

This project is small and run by volunteers. We want issues, pull requests and
discussions to stay useful and friendly for everyone who takes part.

## Expected behavior

- Be respectful and assume good intent; disagree with ideas, not with people.
- Give specific, constructive feedback and accept it the same way.
- Stay on topic and keep reports reproducible and free of secrets or personal data.

## Unacceptable behavior

- Harassment, insults, threats or discriminatory language.
- Publishing someone else's private information.
- Sustained disruption of threads, spam or off-topic promotion.

## Enforcement

The maintainer reviews reports and decides on the response: a warning, editing or
removing comments, locking a thread, or blocking a person from the repository.
Decisions are made case by case and explained to the person concerned when possible.

## Reporting

Report a problem privately, the same way as a security issue (see
[SECURITY.md](SECURITY.md)): use GitHub private vulnerability reporting or write to
the e-mail address given there. Say where it happened and link the comments if you
can. Reports are kept confidential.
